# VIRUM — project page

Static landing page for **VIRUM**, a cursor horror game.

- Live page: https://levitanktv.github.io/Virum-site/
- Downloads: https://github.com/LeviTankTV/Virum-site/releases/latest
- The page is plain HTML and CSS. There is no build step.

## Local preview

Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

The screenshots in `assets/` are captured from the game. They are part of this
repository so the page has no external image dependencies.
