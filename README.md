# VIRUM — project page

Static landing page for **VIRUM**, a cursor horror game in eight acts.

- Live page: https://levitanktv.github.io/Virum-site/
- Downloads: https://github.com/LeviTankTV/Virum-site/releases/latest
- The page is plain HTML and CSS. There is no build step.

## Local preview

Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

The screenshots in `assets/` are captured from Acts I–III of the game. They are
part of this repository so the page has no external image dependencies. No
frame from Acts IV–VIII appears on this page or in the social preview.

`assets/social-preview.png` is the Open Graph image (1280×640), linked from the
`og:image` meta tag.
